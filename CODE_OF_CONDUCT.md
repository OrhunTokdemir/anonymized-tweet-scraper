# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Its full text is the code of conduct for this project.

## In short

We want a welcoming, harassment-free community for everyone, whatever their age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

- **Expected:** empathy and kindness, respect for differing opinions, constructive feedback, taking responsibility for mistakes.
- **Not acceptable:** sexualized language or imagery, trolling, insults or personal attacks, harassment, publishing others' private information without their explicit permission, and other conduct that would be inappropriate in a professional setting.

This project deals with offensive-language research, so issues may need to *discuss* offensive terms. Do that factually and only as far as the technical question requires. Never direct such language at people.

## Reporting

Report unacceptable behavior to the maintainer privately, through the maintainer's GitHub profile (https://github.com/OrhunTokdemir). For anything security-related, use the process in [SECURITY.md](SECURITY.md). Reports are handled confidentially.

The maintainer may remove, edit or reject comments, commits, code, issues and other contributions that don't follow this code of conduct, and may temporarily or permanently ban contributors for behavior they consider harmful. See the [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) of the Contributor Covenant.
